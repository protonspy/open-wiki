Open Wiki, drawn before it is written

This is the visual argument for apps/desktop, made in plain HTML so we can disagree about it cheaply. The frame below works — switch panes, start a recording, change the palette and watch it move. Everything under it is the specification the React build should honour: token names match shadcn/ui, so the palette copies straight into globals.css, and every icon is Lucide, so the sprite becomes lucide-react imports one for one.

Two decisions worth attacking first. Amber means provenance — a citation, a source, a page that has one. It is the accent because tracing a claim back to the minute someone said it is the only thing this product does that nothing else does. And the reading surface is warm while everything around it is cold slate: the content is paper, the application is the instrument holding it.

Dark only, deliberately — task 8.1 asks for a dense dark theme and an app that runs for an hour beside a meeting should not glow. A light theme is a later decision, not an omission.

Choose a folder for your workspace

Everything this application stores goes in one folder you pick. It is plain markdown, readable by Obsidian, VS Code or any agent, and it is yours whether or not you keep using this application.
